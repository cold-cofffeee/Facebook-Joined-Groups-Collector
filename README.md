# Facebook Joined Groups Collector

A lightweight **JavaScript snippet** that you can run directly in your browser console to **collect all the Facebook groups you have joined** from the  
[`Groups You’ve Joined`](https://www.facebook.com/groups/joins/?nav_source=tab&ordering=viewer_added) page.  

⚡ The script **excludes pending group requests** and downloads your joined groups as a `facebook_joined_groups.txt` file.

---

## 🚀 Features
- ✅ Auto-scrolls to load all groups  
- ✅ Collects only **joined group links**  
- ✅ Skips **pending / approval-required requests**  
- ✅ Exports results as a `.txt` file  

---

## 📖 Usage Guide

1. Open [Facebook Groups You’ve Joined](https://www.facebook.com/groups/joins/?nav_source=tab&ordering=viewer_added).  
2. Right-click anywhere → **Inspect** → open the **Console** tab.  
3. Copy and paste the script from [`collectJoinedGroups.js`](./collectJoinedGroups.js).  
4. Press **Enter**.  
5. Wait for the script to finish scrolling – a file named **`facebook_joined_groups.txt`** will be automatically downloaded.
